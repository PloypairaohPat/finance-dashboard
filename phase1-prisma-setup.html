Step 01 / 08

Start PostgreSQL
with Docker

Your app currently has no database. This step spins up a real PostgreSQL instance on your machine using Docker — no install, no config files, one command.
⚠
Docker must be running. Open Docker Desktop and wait for the engine to start before running any commands below.
  • Open Docker Desktop and confirm it's running
    The whale icon in your menu bar should be active, not spinning.
  • Run the PostgreSQL container
    This creates a container named finance-db on port 5432. The data persists in a Docker volume.
  • Verify the container is running
    You should see finance-db with status Up.
Start the database
terminal 
# Start PostgreSQL — runs in background, restarts automatically
docker run \
  --name finance-db \
  -e POSTGRES_USER=financeuser \
  -e POSTGRES_PASSWORD=financepass \
  -e POSTGRES_DB=financedb \
  -p 5432:5432 \
  --restart unless-stopped \
  -d postgres:16

# Confirm it's running
docker ps --filter name=finance-db
✓
Expected output: A long container ID, then a row showing finance-db with status Up X seconds. If you see an error about port 5432 already in use, you may have a local Postgres running — stop it first or change the port to 5433:5432 (and update DATABASE_URL in Step 3).

Step 04 / 08

Encryption utility
for access tokens

Plaid access tokens give full read access to someone's bank account. The roadmap requires they are encrypted at rest before being stored in the database. This utility uses AES-256-GCM — the same standard banks use.
  • Create the utils/ folder in your backend
    mkdir utils from your backend root if it doesn't exist.
  • Create utils/encrypt.js with the code below
    Copy the entire block exactly — no changes needed.
  • Create lib/prisma.js — the shared Prisma client
    This pattern prevents creating a new DB connection on every request.
utils/encrypt.js
create this file
// utils/encrypt.js — AES-256-GCM encryption for Plaid access tokens
// Never log, print, or store the plaintext token anywhere else.

const crypto = require('crypto')

const KEY = Buffer.from(process.env.ENCRYPTION_KEY, 'hex')

if (KEY.length !== 32) {
  throw new Error('ENCRYPTION_KEY must be a 64-char hex string (32 bytes)')
}

function encrypt(text) {
  const iv = crypto.randomBytes(12)
  const cipher = crypto.createCipheriv('aes-256-gcm', KEY, iv)
  const encrypted = Buffer.concat([
    cipher.update(text, 'utf8'),
    cipher.final()
  ])
  const tag = cipher.getAuthTag()
  return [iv, tag, encrypted]
    .map(b => b.toString('base64'))
    .join('.')
}

function decrypt(str) {
  const [iv, tag, encrypted] = str
    .split('.')
    .map(s => Buffer.from(s, 'base64'))
  const decipher = crypto.createDecipheriv('aes-256-gcm', KEY, iv)
  decipher.setAuthTag(tag)
  return decipher.update(encrypted) + decipher.final('utf8')
}

module.exports = { encrypt, decrypt }
lib/prisma.js — singleton client
create lib/ folder, then this file

Step 05 / 08

Write schema.prisma

This is the most important step. The schema defines every table in your database. It's designed following all the roadmap best practices: user_id everywhere, Decimal for money, rawJson stored immutably, soft deletes, and indexes on the fields you'll query most.
  • Open prisma/schema.prisma
    It currently has the placeholder content from npx prisma init.
  • Select all and replace with the schema below
    Delete everything in the file and paste in the full block below. Do not modify anything yet.
  • Save the file
    Don't run any Prisma commands yet — that's Step 6.
prisma/schema.prisma — complete file
replace entire file contents
// prisma/schema.prisma

generator client {
  provider = "prisma-client-js"
}

datasource db {
  provider = "postgresql"
  url      = env("DATABASE_URL")
}

// ── User ──────────────────────────────────────────────
// Single hardcoded user for now. Schema is multi-user
// ready: user_id is on every table from day one.
model User {
  id        String   @id @default(cuid())
  email     String   @unique
  createdAt DateTime @default(now())
  updatedAt DateTime @updatedAt

  plaidItems   PlaidItem[]
  accounts     Account[]
  transactions Transaction[]
}

// ── PlaidItem ─────────────────────────────────────────
// One row per connected bank. Stores the encrypted
// access_token and the sync cursor for delta fetches.
model PlaidItem {
  id              String    @id @default(cuid())
  userId          String
  plaidItemId     String    @unique
  accessToken     String    // AES-256-GCM encrypted — never store plaintext
  institutionId   String?
  institutionName String?
  cursor          String?   // /transactions/sync cursor — stored per item
  lastSyncedAt    DateTime?
  createdAt       DateTime  @default(now())
  updatedAt       DateTime  @updatedAt

  user     User      @relation(fields: [userId], references: [id])
  accounts Account[]

  @@index([userId])
}

// ── Account ───────────────────────────────────────────
// One row per bank account (checking, savings, credit).
model Account {
  id               String   @id @default(cuid())
  userId           String
  plaidItemId      String
  plaidAccountId   String   @unique
  name             String
  officialName     String?
  type             String   // depository | credit | investment | loan
  subtype          String?  // checking | savings | credit card | etc.
  mask             String?  // last 4 digits
  currentBalance   Decimal? @db.Decimal(12, 2)  // Decimal — never Float for money
  availableBalance Decimal? @db.Decimal(12, 2)
  isoCurrencyCode  String?
  createdAt        DateTime @default(now())
  updatedAt        DateTime @updatedAt

  user         User          @relation(fields: [userId], references: [id])
  plaidItem    PlaidItem     @relation(fields: [plaidItemId], references: [id])
  transactions Transaction[]

  @@index([userId])
}

// ── Transaction ───────────────────────────────────────
// Core table. rawJson is immutable — it stores the exact
// Plaid response and is never modified after insert.
// All other columns are derived/cleaned from rawJson.
model Transaction {
  id                 String    @id @default(cuid())
  userId             String
  accountId          String
  plaidTransactionId String    @unique
  amount             Decimal   @db.Decimal(12, 2)  // positive = debit, negative = credit
  isoCurrencyCode    String?
  date               DateTime  // stored in UTC always
  name               String    // raw merchant string from Plaid
  merchantName       String?   // cleaned merchant name (Phase 2)
  categoryPrimary    String?   // e.g. "Food and Drink"
  categoryDetailed   String?   // e.g. "Food and Drink > Restaurants"
  pending            Boolean   @default(false)
  deletedAt          DateTime? // soft delete — never hard-delete transactions
  rawJson            Json      // immutable Plaid response — never UPDATE this
  createdAt          DateTime  @default(now())
  updatedAt          DateTime  @updatedAt

  user    User    @relation(fields: [userId], references: [id])
  account Account @relation(fields: [accountId], references: [id])

  // Indexes on the two most common query patterns
  @@index([userId, date])
  @@index([userId, categoryPrimary])
}
What each table does
TablePurposeKey field
User Single user for now. Having it from day 1 means zero refactoring if you add multi-user later. id (cuid)
PlaidItem One row per connected institution. Replaces your in-memory tokenStore. accessToken (encrypted)
cursor
Account Each checking/savings/credit account under a PlaidItem. currentBalance (Decimal)
Transaction Every transaction. rawJson column is the source of truth — never modified. rawJson (Json) — immutable
deletedAt (soft delete)

Replace /exchange-token endpoint
server.js — exchange-token route
// REPLACE your existing /exchange-token handler with this:
app.post('/exchange-token', async (req, res) => {
  try {
    const { public_token } = req.body

    // Exchange public token for access token
    const tokenResponse = await plaidClient.itemPublicTokenExchange({
      public_token,
    })
    const { access_token, item_id } = tokenResponse.data

    // Encrypt before storing — never store plaintext
    const encryptedToken = encrypt(access_token)

    // Get institution details from Plaid
    const itemResponse = await plaidClient.itemGet({ access_token })
    const institutionId = itemResponse.data.item.institution_id

    let institutionName = null
    if (institutionId) {
      const instResponse = await plaidClient.institutionsGetById({
        institution_id: institutionId,
        country_codes: ['US'],
      })
      institutionName = instResponse.data.institution.name
    }

    // Upsert PlaidItem — safe to call multiple times
    const plaidItem = await prisma.plaidItem.upsert({
      where:  { plaidItemId: item_id },
      update: { accessToken: encryptedToken },
      create: {
        userId:          DEFAULT_USER_ID,
        plaidItemId:     item_id,
        accessToken:     encryptedToken,
        institutionId,
        institutionName,
      },
    })

    // Fetch and store accounts
    const accountsResponse = await plaidClient.accountsGet({ access_token })
    const accounts = accountsResponse.data.accounts

    for (const acct of accounts) {
      await prisma.account.upsert({
        where:  { plaidAccountId: acct.account_id },
        update: {
          currentBalance:   acct.balances.current,
          availableBalance: acct.balances.available,
        },
        create: {
          userId:          DEFAULT_USER_ID,
          plaidItemId:     plaidItem.id,
          plaidAccountId:  acct.account_id,
          name:            acct.name,
          officialName:    acct.official_name,
          type:            acct.type,
          subtype:         acct.subtype,
          mask:            acct.mask,
          currentBalance:  acct.balances.current,
          availableBalance:acct.balances.available,
          isoCurrencyCode: acct.balances.iso_currency_code,
        },
      })
    }

    res.json({ success: true, institutionName })
  } catch (err) {
    console.error('exchange-token error:', err.message)
    res.status(500).json({ error: err.message })
  }
})

Replace /api/transactions endpoint
server.js — transactions route
// REPLACE your existing /api/transactions handler with this:
app.get('/api/transactions', async (req, res) => {
  try {
    // Get all PlaidItems for this user
    const items = await prisma.plaidItem.findMany({
      where: { userId: DEFAULT_USER_ID },
    })

    if (items.length === 0) {
      return res.json({ transactions: [] })
    }

    let allTransactions = []

    for (const item of items) {
      const access_token = decrypt(item.accessToken)

      // Fetch transactions from Plaid
      const response = await plaidClient.transactionsGet({
        access_token,
        start_date: '2024-01-01',
        end_date:   new Date().toISOString().split('T')[0],
      })

      const txns = response.data.transactions

      // Persist each transaction to DB (upsert = safe to re-run)
      for (const txn of txns) {
        const account = await prisma.account.findUnique({
          where: { plaidAccountId: txn.account_id },
        })
        if (!account) continue

        await prisma.transaction.upsert({
          where:  { plaidTransactionId: txn.transaction_id },
          update: {
            pending:         txn.pending,
            amount:          txn.amount,
            categoryPrimary: txn.personal_finance_category?.primary ?? null,
          },
          create: {
            userId:            DEFAULT_USER_ID,
            accountId:         account.id,
            plaidTransactionId:txn.transaction_id,
            amount:            txn.amount,
            isoCurrencyCode:   txn.iso_currency_code,
            date:              new Date(txn.date),
            name:              txn.name,
            merchantName:      txn.merchant_name,
            categoryPrimary:   txn.personal_finance_category?.primary ?? null,
            categoryDetailed:  txn.personal_finance_category?.detailed ?? null,
            pending:           txn.pending,
            rawJson:           txn,  // immutable — never update this column
          },
        })
        allTransactions.push(txn)
      }
    }

    res.json({ transactions: allTransactions })
  } catch (err) {
    console.error('transactions error:', err.message)
    res.status(500).json({ error: err.message })
  }
})
