# M7.3 — before / after, part 2: everything converted after the endpoints

Generated 2026-09-17 against the **demo seed** in the local dev database.
Part 1 (`m7.3-reconciliation.md`) covers the six endpoints and is frozen. This part covers
the consumers the inventory found afterwards: the weekly digest, the Financial Score, the
alert detectors, subscriptions, and how transaction rows render.

**BEFORE** is the real pre-conversion code, run from a git worktree at commit `81b6aea2`
— not a description of it. Where a figure is attributed, the old rule is also rebuilt row by
row and checked against that old code, so the attribution explains what it actually did.

This machine runs in **America/New_York**. That matters for
BEFORE: the old code bucketed months in local time, and the demo seed stores dates at UTC
midnight, so here a transaction on the 1st lands on the previous local evening.
